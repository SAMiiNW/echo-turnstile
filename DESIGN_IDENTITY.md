# Echo Turnstile identity brief

- Mechanism signature: a time-bounded semantic deduplication lane compares each public request with still-active predecessors and stores the exact matching request IDs.
- Product metaphor: an intake turnstile that admits novel tickets and diverts echoes to the earlier ticket they repeat.
- Narrative voice: brisk operations copy. Sentences read like intake stamps and routing receipts.
- Visual grammar: near-black terminal, acid mint scan line, warm ticket stock, oversized serial numbers, horizontal motion.
- Interaction grammar: open one lane, feed a ticket from the right, scan, then see it travel to ADMITTED or REDIRECTED.
- Documentation style: operating rule, receipt anatomy, cooldown behavior, then live run.
- Evidence story: public payload digest, active comparison set, exact duplicate IDs, route state, and finalized transaction form one receipt.
