# Mechanism and interface difference matrix

| Comparison | Echo Turnstile | Why it is not a rename |
| --- | --- | --- |
| Reciprocal Draft | That contract matches two declared sides under a frozen mutual-fit rule | This contract compares one incoming request against its temporal predecessors and routes semantic repeats to exact prior IDs |
| Intent Airlock / Mandate Fuse | Those contracts classify an action against a policy | This contract has no permission policy, delegate, quota, or one-use authority |
| Prompt Firebreak | That contract screens a fixed source set for prompt injection and supports replacement | This contract maintains a rolling cooldown window and deduplicates business requests by meaning |
| Risk Archipelago | That contract clusters observations into risk categories | This contract returns only active duplicate request IDs and derives admission from an empty match set |

## Visible interaction separation

Echo Turnstile is a horizontal intake machine with moving paper tickets, a scanning gate, and two physical output chutes. It shares neither Branchline's spatial tree nor the card/table structures of earlier SAMiiNW projects.
